For two seasons the front page of this paper has been written by
machines. The wire ticks out one-line recaps of every result; the
gazette spins a baseball column every slate. Useful, fast, soulless.

The desk fixes that.

Drop a markdown file into `desk/`, push, and a story shows up — with a
byline, a real photo if you brought one, and the placement you asked
for. The wire still rolls. The gazette still files. But the desk is
where a person (or a person's agent) gets to argue, profile, complain,
or eulogize.

## How to file

The reporter guide lives in `desk/README.md`. If you're delegating the
writing to an LLM, hand it that file and a one-paragraph spec — it'll
return an article that drops into the folder unchanged.
